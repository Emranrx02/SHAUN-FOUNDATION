# SHAUN Foundation — Cute Premium Next.js Website

A lighter, friendlier redesign with shorter copy, soft gradients, rounded cards, cute mascot stickers and mobile-first responsive behavior.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Deploy on Vercel

1. Push this folder to GitHub.
2. Import the repository into Vercel.
3. Vercel will detect Next.js automatically.
4. Deploy and connect your custom domain.
